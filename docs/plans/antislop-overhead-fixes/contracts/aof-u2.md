Unit: aof-u2

## Objective
A main-session Stop is allowed, with no file write by the agent, while a dispatched reviewer is still running.
In stop-gate-core.sh's Stop branch, Stop passes when the number of fresh, unsatisfied, non-advisory
`.review-join.<unit>` stamps is at least the number of undeferred pending-review flags. Fresh means at most
1800 s since the stamp's own timestamp. Each allowed Stop logs `stop-allowed=review-in-flight units=<ids>`.
Every other case behaves exactly as today. Delete the orchestrator instruction that writes `defer:` on a
background reviewer dispatch, which Claude Code refuses headlessly as a sensitive-file edit. This is spec
Step 2 (P2, alt 2A).

## Retrieval
Fast path, no tracker issue. Spec: `docs/plans/antislop-overhead-fixes/spec.md`, "Step 2 (aof-u2)" and
"Context, P2". This file is the contract of record.

## Ordered edits
1. Add `REVIEW_INFLIGHT_MAX_AGE_S=1800` near the top of stop-gate-core.sh's review-join section, with a
   comment explaining it.
2. Add `review_inflight_units <dot-dir>`. It is **read-only**: no `rm`, no write, no state_* mutator. It
   iterates `"$dot"/.review-join.*`, skipping any name that ends in `.advisory` and any stamp whose first line
   holds `mode=advisory`. For each remaining stamp it:
   - parses `unit=` with the same regex and traversal guard as `review_join_state()`, skipping a malformed
     stamp **without deleting it**;
   - parses the first whitespace field as UTC ISO-8601, and skips the stamp if the field is unparseable or
     older than `REVIEW_INFLIGHT_MAX_AGE_S`. Use `date -u -d` with a `date -j -f` fallback, as the file
     already does for portability; if neither parses, skip, which fails closed and leaves Stop blocked;
   - skips the unit if `.claude/reviewed/<unit>.blocked` or `.escalated` exists;
   - skips the unit if it is already satisfied, using the same rule `review_join_state()` uses: a
     format-valid `PASS <unit> ` or `FAIL <unit> ` marker newer than the stamp's `prior_mtime`. Factor the
     satisfied test into a shared helper only if that helper has no side effects; otherwise duplicate the
     comparison.

   It prints the remaining unit ids, one per line.
3. In the Stop branch's `for flag` loop, keep the existing `blocked=true`, and also:
   - increment a counter `undeferred` in the `*)` arm;
   - set `empty_reason=true` in the `"defer: "|"skip: "` arm, where a defer or skip carries no reason.

   After the loop, if `blocked=true`, `empty_reason` is not true and `undeferred` is at least 1, compute
   `inflight=$(review_inflight_units "$dot")`. An empty-reason flag is never excused by a stamp. If the number
   of in-flight lines is at least `undeferred`, then:
   - append `<ts> stop-allowed=review-in-flight units=<comma-joined ids>` to review-audit.log through
     `state_append_audit_log`, deduplicated against the last line in the same way as the `defer:` arm;
   - call `allow`.

   Otherwise call the existing `block` with its message unchanged, followed by this sentence: " A reviewer
   dispatched with a `Unit:` line lets Stop through for 1800 s on its own; no flag write is needed."

  `.review-join.<id>.advisory` with `mode=advisory` (:113-114). The route gate writes no stamp under

  `marker_format_valid()` is at :220.
- Flags are not bound to units, and the reviewer clears at most one flag per satisfied stamp (M3,
  stop-gate-core.sh:435-447). That is why the allow condition compares counts.
- The Stop branch already skips everything under `reviewGating.mode: off` (:511).
